## ФИЛОСОФИЯ ПРОДУКТА

Путеводители «Как местный» — это НЕ просто сборник информации из интернета.
Это живой продукт с личностью, голосом и опытом. Основатель Кирилл Андреев
стоит за каждым путеводителем. Люди идут на людей.

**Конкуренты и чем мы лучше:**
- Винский/awd.is — огромная база, но устаревший дизайн, нет мобильной версии, токсичная модерация
- Авиасейлс «Короче» — современно, но тексты пустые, нет глубины
- Оранжевый гид — книга, не обновляется, нет кликабельных карт
- Lonely Planet — кризис именно потому что не перешли от книги к живому продукту

**Наша ниша:** интерактивный + красивый + кликабельные карты + структурированный +
мобильный + в Telegram + личная история основателя. Никто так не делает.

## ФОРМАТЫ ПРОДУКТА

### 1. Веб-сайт (GitHub Pages) — основной формат
- URL: `https://andreev032.github.io/Travel-Bot/guides/[регион]/`
- Многостраничный, с навигацией между разделами
- Реальные фото (Wikimedia Commons CC лицензия или собственные)
- Кликабельные Google Maps ссылки
- Анимации при скролле
- Блок авторского тура с Кириллом

### 2. PDF — для маркетплейсов
- Генерируется из HTML через Playwright (headless Chrome) или WeasyPrint
- Формат A4, книжная ориентация
- Минимум 20 страниц, максимум 60
- Те же фото что и в веб-версии
- Кликабельные ссылки в PDF (Google Maps, бот)
- Продаётся на: WB Цифровой, Ozon, Яндекс Маркет

**Требования маркетплейсов:**
- WB Цифровой: PDF, ИП или самозанятый, доступ сразу после оплаты
- Ozon: PDF/EPUB, до 100 МБ
- Яндекс Маркет: PDF, категория «Книги и журналы»
- Цена на маркетплейсах: 149-299 ₽ за регион

### 3. Telegram WebApp — открывается из бота
- Кнопка «Путеводители» → список регионов → открывает index.html
- Адаптирован под мобильный экран
- Навигация через Telegram Back Button

## СТРУКТУРА СТРАНИЦЫ — ШАБЛОН

### index.html (главная регион)

1. **НАВИГАЦИЯ** (sticky header)
   - Лого «Как местный» слева
   - Ссылки на разделы: О регионе / Места / Кухня / Советы / Тур
   - Кнопка «Открыть бота» справа
   - На мобиле: бургер-меню

2. **HERO (100vh)**
   - Фоновое фото региона (реальное, Wikimedia CC)
   - Overlay: `rgba(0,0,0,0.55)`
   - Надпись сверху: `[СТРАНА/РЕГИОН] · КАК МЕСТНЫЙ` (letter-spacing 4px, акцент)
   - Главный заголовок: название региона (clamp)
   - Подзаголовок курсивом: слоган региона
   - Кнопка скролла вниз

3. **О РЕГИОНЕ** (Wikipedia-стиль но живым языком)
   - 3-4 абзаца реального контента
   - 3 цифры-факта в ряд (яркие, запоминающиеся)

4. **КОГДА ЕХАТЬ**
   - 3 карточки сезонов с реальными температурами

5. **КАК ДОБРАТЬСЯ**
   - Рейсы по городам с ценами
   - Лайфхак-блок

6. **ПРЕВЬЮ МЕСТ** (3-4 карточки с фото)
   - Кнопка «Все места →» → places.html

7. **ПРЕВЬЮ КУХНИ** (3 блюда)
   - Кнопка «Вся кухня →» → food.html

8. **БЛОК ТУРА** (авторский тур с Кириллом)
   - Личная история
   - Стоимость и что включено
   - Кнопки выбора месяца → бот

9. **FOOTER**
   - Навигация по разделам
   - Ссылка на бот
   - © Как местный 2026

### places.html (места)

- Каждое место: большое фото (400px высота) + название + описание + Google Maps кнопка
- Фильтры по типу: природа / города / история / активности
- Сортировка: по популярности / по маршруту

### food.html (кухня)

- Каждое блюдо: фото + название + описание + цена + где попробовать
- Раздел «Сувениры из еды»
- Раздел «Где есть» (рекомендации кафе)

### tips.html (советы и традиции)

**ВАЖНО — раздел «Традиции и уважение» писать серьёзно и конкретно:**

```
ОДЕЖДА — это не рекомендация, это уважение к культуре

Женщинам:
• Плечи и декольте закрыты ВСЕГДА — не только в мечети, но и в сёлах
• Короткие юбки и открытые шорты неуместны в горных аулах
• В мечеть — обязательно платок и одежда до щиколоток
• Купальник — только на пляже, не на улице города

Мужчинам:
• Шорты только ниже колен, лучше брюки в сёлах
• В мечеть — длинные брюки, плечи закрыты
• Без маек-безрукавок в населённых пунктах

Всем:
• Не фотографируй людей без разрешения — особенно женщин
• Не входи в мечеть во время намаза если не мусульманин
• Алкоголь в общественных местах — табу
• Громкая музыка и шумное поведение в сёлах — неуважение
```

## ФОТО — СТАНДАРТ

### Источники (приоритет по порядку):
1. **Собственные фото** — лучший вариант, уникальный контент
2. **Wikimedia Commons** — полностью открытая лицензия CC
   - Поиск: `https://commons.wikimedia.org/wiki/Category:[название места]`
   - Формат URL: `https://upload.wikimedia.org/wikipedia/commons/[путь]`
3. **Unsplash** — лицензия Unsplash (бесплатно для коммерции)
   - Указывать автора: `Photo by [имя] on Unsplash`
4. **Pexels** — лицензия CC0

### Запрещено:
- Google Images, Яндекс Картинки
- Пинтерест
- ВКонтакте, Instagram

### Технические требования:
- Минимальное разрешение: 1200px по ширине
- Формат: WebP (с fallback JPEG)
- Hero фото: минимум 1920x1080px
- Карточки мест: соотношение 16:9 или 4:3
- Размер файла: до 500 КБ (оптимизировать через squoosh.app)

### Google Maps ссылки — ТОЛЬКО реальные:
```
Формат: https://www.google.com/maps/search/[название+место]/@[lat],[lng],[zoom]z
Пример: https://www.google.com/maps/search/Сулакский+каньон+Дагестан/@43.009444,46.827778,12z
```
НЕ использовать выдуманные `maps.app.goo.gl` — они не работают!

## КОНТЕНТ — СТАНДАРТ КАЧЕСТВА

### Голос и тон:
- Живой, от первого лица когда уместно
- Конкретные факты и цифры, не абстракции
- Лайфхаки которых нет в обычных гайдах
- Честность — если что-то не идеально, говорить об этом

### Запрещено:
- «Живописный», «удивительный», «захватывающий» без конкретики
- Копипаст из Википедии без переработки
- Выдуманные цены и расстояния — только проверенные данные
- Обобщения без источника

### Структура описания каждого места:
1. Что это и почему стоит ехать (1-2 предложения — крючок)
2. Конкретные факты (размеры, история, рекорды)
3. Практическая информация (как добраться, время, цена)
4. Лайфхак от «местного»

### Бюджет — всегда реальный:
Брать из актуальных источников (Авиасейлс, Банки.ру, отзывы туристов).
Обновлять при создании путеводителя. Указывать год актуальности.

## PDF ВЕРСИЯ — ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ

### Параметры:
- Размер: A4 (210 × 297 мм)
- Поля: 20мм со всех сторон
- Шрифты встроены в PDF
- Минимум 20 страниц

### Структура PDF:
1. Обложка (1 стр) — фото региона на весь разворот + название
2. Содержание (1 стр) — с кликабельными якорями
3. О регионе (2-3 стр)
4. Практическая информация (2 стр) — добраться, бюджет, сезоны
5. Места (8-12 стр) — каждое место на полстраницы с фото
6. Кухня (2-3 стр)
7. Советы и традиции (2 стр)
8. Авторский тур (1 стр)
9. Контакты и QR-код бота (1 стр)

### Генерация PDF из HTML:
```bash
# Playwright (рекомендуется — лучшее качество)
pip install playwright --break-system-packages
playwright install chromium
python generate_pdf.py

# generate_pdf.py:
from playwright.sync_api import sync_playwright
with sync_playwright() as p:
    browser = p.chromium.launch()
    page = browser.new_page()
    page.goto('file:///path/to/index.html')
    page.pdf(path='dagestan_guide.pdf', format='A4', print_background=True)
    browser.close()
```
