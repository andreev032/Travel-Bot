# Интерактивный онбординг

`INTERACTIVE_ONBOARDING_ENABLED=1` включает расписание из 12 сообщений для пользователей, которые впервые запускают бота в личном чате после включения. Старые автоматические рассылки заменены. Кнопки уже отправленных сообщений остаются рабочими.

Новые задания и отметки захвата хранятся в существующей `onboarding_messages`. Диапазон `day` от `-38512` до `-38501` зарезервирован под задания, от `-38612` до `-38601` под захваты. В первом диапазоне `sent_at` хранит время отправки по расписанию в UTC, во втором время захвата в UTC. Исторические значения `day >= 0` сохраняются. Миграции не требуются.

Планировщик атомарно перемещает запись в диапазон захватов перед вызовом Telegram. Неудачные или неподтверждённые попытки могут привести к пропуску сообщения. При рестарте повторной попытки не будет. Через пять минут после срока ожидающие задания истекают.

Для запуска разверните версию и включите флаг после остановки старых реплик. Для остановки новой цепочки уберите флаг. Тесты запускаются командой `python -m unittest discover -s tests -v`. Переменная `ONBOARDING_LOCAL_TEST_DSN` включает тесты с временной локальной PostgreSQL. Тесты используют заглушки Telegram.
